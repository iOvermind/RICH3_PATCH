# 大富翁3 Patch

> 《大富翁3》的修正檔。選好遊戲資料夾按一下，修掉免光碟、農曆崩潰、獎金與物價錯誤，並補上缺失的語音。

---

## 這是什麼

《大富翁3》是 1996 年的遊戲，在現代環境下有幾個直接影響遊玩的問題：需要光碟或顏色密碼才能啟動、內建日曆只到 2018 年而之後農曆會崩潰、若干獎金與物價數值原本就有誤、部分語音檔缺失或錯置。

這個工具一次修完，全部自動處理，不需要你懂任何技術細節。

它是 **Rich Patch Series** 的一員，與《大富翁2》的修正檔操作方式相同。

**主要功能**

- **免光碟、免顏色密碼**——不用再找光碟或翻說明書。
- **修好農曆**——日曆改為以執行當下為基準、往前 10 年往後 30 年（共 40 年），解決 2018/6/6 之後農曆崩潰的問題，並修正 2 月直接跳到 3 月的異常。
- **解鎖多人競賽地圖**——多人地圖可以一個人玩，對手換成電腦。
- **修正獎金與物價**——基隆廟口天婦羅獎金（200 → 2000）、「表彰先進個人」新聞獎金（3000 → 5000）、台北地圖新生南路蓋屋價（3600 → 360）、建國北路二層房過路費（200 → 2000）、賭骰子背景倍率顯示（x8 → x15）、住院與坐牢時「免付過路費」字樣的位置偏移。
- **補齊語音**——用 GPT-SoVITS 補上原版缺失或錯誤的語音（如「加盟萬巒豬腳得利 30%」、「行人違規穿越馬路」等）。
- **自動備份**——動到的檔案都會先複製成 `.bak`；重複執行不會覆蓋最初的備份。

## 取得與安裝

### 系統需求

| 項目 | 需求 |
| :--- | :--- |
| 作業系統 | Windows 7 以上（32/64 位元皆可） |
| 其他 | 無。單一執行檔，不需安裝任何執行期 |
| 遊戲 | 已安裝的《大富翁3》，資料夾中要有 `RICH3.EXE` |

### 相容性

| 遊戲版本 | 狀態 |
| :--- | :--- |
| Steam 典藏版 | 已實測確認 |
| 磁片版 / 重訂光碟版 | 程式內含對應特徵碼，但手邊無實體檔案，**未經測試** |

### 下載

至 [Releases](../../releases) 下載 `rich3_patch.exe`，放哪裡都可以，不需要安裝。

## 快速開始

**Steam 典藏版需要先做一件事**：把 Steam 的《典藏大富翁》資料夾裡 `content` 的**所有內容**複製到 `three` 資料夾中。這是遊戲本身的檔案配置問題，與本工具無關。

接著：

1. 雙擊 `rich3_patch.exe`，會開啟一個小視窗。
2. 看一下上方的**遊戲目錄**是否正確。不對的話按「**瀏覽...**」選到《大富翁3》的安裝資料夾（就是有 `RICH3.EXE` 的那層）。
3. 按「**開始**」。
4. 下方日誌會逐條顯示六個步驟的處理結果。**日曆要逐日換算農曆，會跑數十秒**，這是正常的，不要以為當掉了。
5. 跑完會跳出摘要視窗。開遊戲即可。

## 常見問題

#### 開啟時出現「Windows 已保護您的電腦」或防毒警告

這支程式使用自簽憑證，沒有向憑證機構購買，因此 Windows SmartScreen 會跳出警告。若你是從本專案的 [Releases](../../releases) 頁面下載的，可以點「其他資訊」→「仍要執行」。

不放心的話，Release 附有 `SHA256SUMS.txt`，可以比對確認檔案沒有被掉包：

```powershell
Get-FileHash .\rich3_patch.exe -Algorithm SHA256
```

#### 為什麼要跑數十秒？

第 2 步要產生日曆檔，程式得逐日換算 14612 天（40 年）的國曆與農曆對照並寫成兩個檔案。這是整個流程中最花時間的部分，沒有卡住。

#### 日誌顯示「找不到特徵碼或已修改」

代表這個位置已經改過了，或你的遊戲版本不在支援清單內。前者是正常的——重複執行本工具就會看到這個訊息，不會有問題。

#### 我可以重複執行嗎？

可以。第一次執行時會把動到的檔案備份成 `.bak`，之後再跑都不會覆蓋這些最初的備份，所以隨時可以還原回原版。

但要注意：**日曆檔每次執行都會重新產生**，內容以執行當下的日期為基準。這是刻意的，讓日曆範圍隨時間往後推移。

#### 怎麼還原成原版？

把遊戲資料夾裡的 `*.bak` 檔案改名回原本的檔名（覆蓋掉已修改的那份）即可。

#### 遊戲裡的農曆還是不對

確認你是在**修改後**開的遊戲，且沒有把 `Cald.a` / `Cald.b` 還原回 `.bak`。若日期超出「執行當下往前 10 年、往後 30 年」的範圍，重新執行一次本工具即可把範圍往後推。

## 已知限制

- 磁片版與重訂光碟版的特徵碼**未經實機測試**。若你手上有實體版本且試過，歡迎回報結果。
- 日曆涵蓋範圍為執行當下往前 10 年、往後 30 年。超過範圍需要重新執行一次。
